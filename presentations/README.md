## 이전 버전

`history/`에 이전 완성 산출물 12개를 보관했다. 최초 개요, 처리과정, 테스트 재구성, 사근진 사례·좌표 비교, 발표 표현·사진 강조 등의 수정 이력이다. 여러 파일에 ‘최종’이 있어도 위 `latest/` 파일이 이번 정리 시점의 대표본이다.

## 제작·검사 기록

`build/`에는 11개 작업 폴더의 JavaScript/Python 제작 코드와 검사·변경·매핑 기록을 보존했다. [build-index.json](build-index.json)에 포함 파일과 제외한 중간 PPTX·렌더 폴더를 기록했다.

과거 제작 스크립트는 당시 PC 경로와 artifact-tool 환경을 사용하므로 별도 설정 없이 재실행되는 빌드 시스템은 아니다. 읽기와 수정 경위 확인을 위한 원본 기록이며, 최신 PPTX 자체를 새로 제작하거나 변경하지 않았다.
