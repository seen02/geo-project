# 테스트 입력 자료

기존 `geo_slueth_test`의 사진·출처·정답표와 초기 intake 기록을 보관했다. 파일명은 원본과 동일하다. 공개본의 사진에서 GPS 메타데이터를 제거했다.

| 묶음 | 내용 |
|---|---|
| `geo_test_images/` | EXIF 등을 제거해 준비한 도로 사진 |
| `terrain_test_images/` | 지형 사진·사용자 제공 실험 사진 |
| `investigation_1028/` | 초기 검사·OCR·가장자리·변형 이미지 |
| [geo_test_answers.md](geo_test_answers.md) | Hobart 테스트 사진 2장의 위치·출처·라이선스 |
| [terrain_test_answers.md](terrain_test_answers.md) | 노르웨이 지형 사진 2장의 위치·출처·라이선스 |

정답표의 좌표는 출처에 기재된 위치이며 독립 측량한 값은 아니다. 모든 파일에 정답 좌표가 있는 평가셋은 아니다. 특히 `test_*`, `candidate_*`, 메신저 파일명은 모델별 통제된 벤치마크나 독립 표본 수를 뜻하지 않는다.

블라인드 실험에서는 결과를 확정하기 전 정답표를 열지 않고, 같은 원본의 변형·연사·재검증을 분리해야 한다. 사용자 제공 사진에는 별도 공개 라이선스를 부여하지 않았다.
