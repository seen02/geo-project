`completed`는 조사 프로세스가 끝났다는 뜻이다. `review`는 추가 확인이 필요하다는 사용자 결과 상태다. 위치의 정답 여부나 정밀 오차가 독립적으로 검증됐다는 뜻은 아니다.

## 폴더 구성

- `summary.json`: 실행 시도·모델 기록·시간·좌표 의미·현재 상태. 과거에 기록하지 않은 모델은 null로 둔다.
- `report.json`: 현재 앱 리포트의 열람용 내보내기. 이미지 경로를 이 보관 폴더에 맞췄다.
- `evidence/`: 리포트에 연결된 최종 근거·지도 이미지와 지도 메타데이터.
- `attempts/`: 각 시도의 구조화된 최종 응답. 실패 시 최종 응답이 없을 수 있다.
- `artifacts/<시도>/`: 조사 중 만들어진 코드·비교·계산·intake·원본 출처 자료. 실패 자료도 역사적 기록으로 남아 있으므로 완성 근거로 자동 취급하지 않는다.
- [index.json](index.json): 전체 요약 목록.

원시 이벤트·내부 대화·stderr·인증·모델 캐시는 보관하지 않는다. 이 폴더는 앱 의뢰를 그대로 복원하는 백업 형식이 아니다.
