각 폴더에는 결과·후보 장부·원본/크롭·참고사진·지도·계산 입력과 출력·보조 코드가 남아 있다. 파일명은 기존 작업과 대조할 수 있도록 보존했다. 캐시와 모델 가중치는 제외했다.

## 결과를 읽는 기준

- **시설 식별, 촬영 구역, 카메라 위치**는 서로 다른 확인 수준이다.
- **보고 반경**은 대략적인 탐색 범위일 수 있다. 통계적 신뢰구간으로 바꾸지 않는다.
- **유사도·인라이어·픽셀 RMS**는 해당 비교나 계산의 지표다. 정답 확률이나 지상 오차와 다르다.
- **실제 좌표 비교**도 정답을 몰랐던 독립 평가인지 확인한다.
- 실패·불일치·미해결 사례를 성공 사례와 함께 보관한다.
