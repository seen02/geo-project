# geo-sleuth 분석 정리

## 무엇인가

geo-sleuth는 **AI 에이전트가 사진의 촬영 장소를 조사하도록 안내하는 스킬과 Python 도구 모음**이다. 하나의 위치 예측 모델이나 단일 API가 아니다. 에이전트는 관찰·가설·도구 선택·판단을 담당하고, 도구는 실제 파일 처리·조회·계산을 담당한다.

원본: [Oldcircle/geo-sleuth](https://github.com/Oldcircle/geo-sleuth). 이번 분석에 사용한 스냅샷은 `9a29a51cbe890ff06fdf66ba4f74db6b2186d8f1`이다. 저장된 소스와 당시 설치된 스킬은 줄바꿈을 정규화한 텍스트 비교에서 일치했다. 원본의 일반 성능 주장을 이 프로젝트의 실험 성과로 가져오지 않는다.

## 조사 흐름과 산출물

| 단계 | 하는 일 | 대표 도구 | 남는 자료 |
|---|---|---|---|
| 초기 검사 | GPS·메타데이터·글자·가장자리 확인 | `intake.py`, `exif.py`, `ocr.py`, `imgprep.py` | EXIF/OCR JSON, intake 기록, 크롭 |
| 후보 만들기 | 시설·도로·지형 등 관찰을 가설로 구성 | `clues.py`, `regions.py`, `poi.py`, `osm.py` | 단서·후보 지역·시설 좌표 |
| 후보 관리 | 지지·반박·미사용 근거와 다음 검사 기록 | `board.py` | `board.json`, 검사·보고 결과 |
| 비교 자료 확보 | 공개 사진·거리사진·위성영상 조회 | `gsv.py`, `tiles.py` 등 | 참고사진, 파노라마 목록, 지도·좌표 메타데이터 |
| 순위화 | 후보를 기계적으로 비교해 볼 대상을 줄임 | `match.py`, `sat_scan.py` | 비교 점수·특징 대응·상위 이미지 패널 |
| 지형·기하 검사 | 능선·고도·각도·카메라 위치의 일관성 확인 | `terrain.py`, `pose.py`, `geo.py`, `sun.py` | 투영 이미지, 위치·자세·민감도 결과 |
| 결과 정리 | 지도·비교 패널·결론과 한계 구성 | `evidence.py`, `board.py` | `evidence.jpg`, 결과 JSON, 보고서 |

모든 사례에서 모든 도구를 쓰는 것은 아니다. 역이미지 검색 기능은 원본에 포함돼 있지만, 이 저장소의 주요 사례는 역검색을 끄거나 원본 사진의 역검색 업로드 없이 진행한 기록이다. 자세한 조건은 각 보고서를 따른다.

## 기술을 해석할 때 구분할 것

**DINOv2 유사도**는 비교 순위 지표다. 가장 높은 점수가 곧 정답 확률이라는 뜻은 아니다. **SIFT 대응점과 인라이어**도 시점·조명·구도 변화에 영향을 받는다. 자동 순위 이후 실제 구조물과 자료 출처를 확인해야 한다.

**재투영 RMS**는 지정한 대응점에서 사진 픽셀이 얼마나 어긋나는지 나타낸다. 작은 픽셀 오차가 작은 지상 위치 오차를 보장하지 않는다. 기준점 배치·좌표·높이·렌즈 가정이 틀리면 계산은 가까이 맞으면서 위치가 흔들릴 수 있다.

**후보 장부 점수**는 증거를 정리하고 상대 우선순위를 정하는 값이다. 검증된 통계적 정답 확률로 쓰지 않는다. **검사 통과** 역시 입력·기록의 일관성 점검이지 현장 측량 인증이 아니다.

## 이번 프로젝트에서 확인한 문제

- 장소를 확인한 것과 정확한 카메라 위치를 확인한 것은 다르다.
- 강한 시각 특징 대응이 없더라도 시설 형태·주변 배치가 후보를 지지할 수 있지만, 보고 범위를 좁게 잡아서는 안 된다.
- 비교점의 높이나 지도 좌표를 조금 바꾸면 추정 위치가 크게 움직일 수 있다.
- 거리사진 확보 성공과 동일 촬영점 확인 성공은 다르다.
- 지도 파일이 존재해도 타일이 모두 실패한 영상일 수 있다.
- Windows 네트워크·인코딩·없는 도구 경로·모델 혼잡은 조사 품질과 별개의 실행 문제다.

초기 사례에는 `pose.py`의 수평선 안내 문구와 실제 투영 함수 사이의 피치 부호 차이를 기록했다. 원본을 임의 수정하지 않고 실제 투영과 사례별 제한 사항을 보존했다.

## FRAME으로 연결한 부분

FRAME은 조사 스킬을 새로 만드는 대신, 작업별 실행 공간·도구 실행 기록·구조화된 결과·이미지 검사·보류 상태·복구 흐름을 덧붙인다. 한국 지역팩도 외부 팩 경로로 주입해 원본과 분리한다.
