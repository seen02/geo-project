# FRAME 서비스 기획

기준일: 2026-11-04. 구현 현황은 로컬 소스와 실제 조사 결과를 기준으로 작성했다. 고객·사업 가설은 검증된 성과와 구분한다.

## 제품 정의

**레퍼런스 사진을 촬영 위치·방향·비교 근거가 있는 촬영지 리포트로 바꾸는 리서치 도구.**

주요 사용자는 사진가·영상 제작자와 소규모 제작팀이다. 사진 속 장소를 발견한 뒤에도 촬영 방향, 서 있을 위치, 구도의 근거와 답사할 항목을 정리해야 한다는 문제에서 출발했다.

처음 구상한 범위는 원래 촬영지 찾기에서 접근 경로·촬영 계획까지 연결하는 것이다. 현재 자동 조사로 구현한 핵심은 장소 후보·촬영점 추정·근거·남은 확인 사항이다. 출입 허가·현장 접근성·적정 촬영 시간의 실시간 검증은 확보한 출처와 자료 범위에 제한된다.

## 사용자 흐름

| 단계 | 사용자의 행동 | 제공하는 기능 |
|---|---|---|
| 의뢰 | 사진, 제목, 지역·목적·요청사항 입력 | 업로드·샘플 선택·실행 환경 확인·모델 선택 |
| 실행 | 조사 시작 | 작업 생성, 전용 폴더, 대기열, 실제 Codex 조사 |
| 확인 | 실시간 기록 읽기 | 조사 단계·도구 실행 안내·공개 진행 메시지·경과 시간 |
| 검토 | 촬영지 리포트 열기 | 위치 의미, 추정 반경·방향·화각, 근거·출처·한계 |
| 보완 | 결과 편집 또는 재조사 | 수동 스튜디오, 새로 조사, 중간 자료에서 이어받기 |
| 활용 | 자료 저장·공유 준비 | JSON 백업·인쇄/PDF 저장·보고서 확인 |

완료율과 남은 시간은 추정해서 표시하지 않는다. 서버가 받은 실제 단계와 사건을 보여준다. 샘플 리포트는 화면 예시이며 새 의뢰의 실제 결과를 대신하지 않는다.

## 범위 구분

| 범위 | 상태 | 설명 |
|---|---|---|
| 사진 → 실제 조사 → 리포트 | 구현 | 로컬 Codex CLI와 geo-sleuth 연결 |
| 구조화된 결과·이미지 연결 | 구현 | 좌표 의미와 검증 수준에 따라 추가 확인 상태 표시 |
| 실패 안내·중지·재시도·복구 | 구현 | 실행 상태 보존과 제한된 복구 경로 |
| 한국 지역팩 | 초기 구현 | 6개 단서 지침. 국내 지도 전용 자동 수집기는 아님 |
| 비슷한 촬영지 대안 추천 | 확장 가설 | 지정한 지역에서 구도·풍경 조건에 맞는 후보 탐색 |
| 촬영 접근성·허가·시즌 안내 | 보강 과제 | 최신 현장 자료와 별도 검증 필요 |
| 다중 사용자·결제·클라우드 운영 | 미구현 | 현재는 개인 PC의 loopback 서버 |
| 유료 고객 확보·시간 절감 효과 | 미검증 | 인터뷰·실사용 평가 필요 |

## 차별화에서 검증할 질문

기존 이미지 검색으로 장소 이름을 알아낸 이후에도 사용자가 FRAME을 사용할 이유가 있는가? 리포트가 보기 좋은 것을 넘어 **촬영 계획과 확인 행동**을 돕는지 검증해야 한다.

- 사진을 어디에서 어느 방향으로 찍었는지 설명할 근거가 있는가?
- 정확한 촬영점과 시설 대표 좌표의 차이를 사용자가 이해하는가?
- 실패한 검증과 자료 부족이 다음 답사·추가 촬영 질문으로 이어지는가?
- 결과를 팀원에게 전달해 실제 제작 준비에 사용할 수 있는가?

건별 리서치나 프로젝트 묶음 판매는 수익 모델 가설이다. 가격·수요·유료 전환율은 측정하지 않았다.

## 검토했던 확장 방향

초기 기술·서비스 논의에서는 다음 활용도 검토했다. 아래 항목은 구현 기능이나 확정한 제품 로드맵이 아니다.

| 방향 | 위치 식별 이후의 가치 |
|---|---|
| 지역 내 대체 촬영지 | 원하는 풍경·구도·이동 조건에 맞는 후보 비교 |
| 숙소·좌석 전망 확인 | 판매 조건과 사진의 시야가 일치하는지 검토 |
| 게시 전 위치 노출 점검 | 공개 허용 범위에 맞춰 단서와 수정 후보 확인 |
| 여러 사진의 현장 재구성 | 공통 구조물·촬영 시야·모순을 지도에서 연결 |
| 기업 현장 증빙 검토 | 대상 시설과 제출 사진 대응, 부족한 촬영 요청 |
| 옥외광고·입지 검토 | 접근 방향·가림·가시 조건을 근거로 비교 |

## 다음 제품 검증

우선 실제 제작자가 가진 사진으로 리포트를 만들고, 원래 쓰던 검색 방식과 나란히 비교한다. 정확도 외에 조사 시간, 사람이 다시 확인한 항목, 현장 준비에 도움을 준 근거, 재사용 의사를 기록한다. 이를 확인한 뒤 원래 촬영지 조사에 집중할지 조건 기반 추천으로 넓힐지 결정한다.
