## 구현 상태

- **사용 가능한 로컬 흐름:** 의뢰 → 실제 조사 → 진행 기록 → 결과·근거 확인.
- **운영 보완:** 대기열·중지·디스크 복원·혼잡 재시도·중간 자료 이어받기.
- **결과 보완:** 대표점과 카메라 추정점 구분, 반경·방위·화각 분리, 실패 자료 검사, 추가 확인 상태.
- **기술 검증:** 개별 사례 조사와 자동 계약·전송 테스트. 독립 평가셋에 대한 정확도·보류율·비용의 일반 수치는 없음.
- **제품 검증:** 화면과 동작 프로토타입 보유. 고객 인터뷰·유료 수요·업무 시간 절감은 미검증.

## 실제 FRAME 실행 기록

[보관된 5건](../research/frame-runs/README.md)은 모두 조사 프로세스의 `completed` 기록을 갖고 있다. 사용자에게 전달하는 상태는 모두 `review`다. 호수·독산성·사근진·북촌·캠퍼스 사례가 포함된다. 한옥마을 건은 실패 후 두 번째 시도의 완료 결과도 남아 있다.

‘완료’는 작업 실행의 종료 상태, ‘추가 확인’은 결과의 확인 수준이다. 두 상태를 하나의 성공률로 합치지 않는다. 초기 QA 문서의 ‘이후 재조사 미실행’은 해당 변경 당시의 기록이며, 이번에 보관한 후속 실행과 구분한다.
