# 공개 자료 보관 기준

| 경로 | 공개하는 자료 |
|---|---|
| `apps/frame/` | 로컬 웹 앱, 테스트, 실행 안내, 한국 지역팩 |
| `vendor/geo-sleuth/` | 업스트림 코드·테스트·예시와 기존 라이선스 |
| `research/datasets/` | 공개 이용이 허용된 입력 사진이나 직접 촬영한 사진, 출처·정답표 |
| `research/cases/` | 조사 대상 사진과 크롭, 보고서, 검증 수치, 보조 코드 |
| `research/frame-runs/` | FRAME 실제 조사 5건의 공개용 리포트, 입력 사진, 계산·실행 기록 |
| `presentations/build/` | 발표자료 제작 보조 코드 |
| `docs/assets/` | 홈, 의뢰, 진행, 샘플 리포트, 복구 화면 |

공개하지 않는 외부 지도·거리사진·웹페이지의 출처는 조사 결과에 링크로 남긴다. 공개용 사진에서는 GPS 메타데이터를 제거했으며, 원시 EXIF 파일·PPTX·발표자 노트 및 조사용 외부 원본은 공개본 범위에서 제외한다.

FRAME의 `report.json`은 열람용 공개 기록이다. 일부 과거 검증 문서와 보조 코드는 당시 작업 환경의 산출물을 가리킨다. [자료 출처와 이용 조건](../THIRD_PARTY_NOTICES.md)
