# 저장소 정리 시점 검증

검증일: 2026-11-04, Asia/Seoul. 원본 작업 폴더를 새 저장소로 복사한 후 수행했다. 이번 작업에서는 앱의 동작 코드를 수정하지 않았다.

## FRAME 자동 검사

| 실행 | 결과 | 검사 범위 |
|---|---|---|
| `npm run check` | 통과 | 서버·실행기·프런트엔드 JavaScript 문법 |
| `npm test`의 Node 테스트 | 21개 통과, 실패 0 | 도메인·백업·접수·CLI 인자·SSE·결과 파일·대기열·중지·복구·모델·오류·자료 검사 |
| `npm test`의 Python 테스트 | 7개 통과 | 로컬 HTTP 전송·상태 코드·UTF-8·실패 응답·HTML 위장 이미지·인증서 검증 설정 |

**총 28개 통과.** 실제 유료 모델은 호출하지 않았다. 테스트 전용 자식 프로세스와 로컬 HTTP fixture를 사용한다. 위치 추정의 실제 정답률이나 실서비스 운영 성능을 의미하지 않는다.

첫 실행에서는 캐시가 없는 새 폴더에서 `uv`의 Pillow 환경 준비가 지연돼 일부 계약 테스트가 시간 초과했다. 아래 준비 명령으로 의존성을 확보한 후 같은 코드로 전체 검사를 다시 실행해 통과했다. 처음 내려받을 때는 네트워크 접근이 필요하다.

```powershell
# apps/frame 폴더에서 실행
$env:UV_CACHE_DIR = Join-Path (Get-Location) '.local-data/runtime/uv-cache'
'[]' | uv run tools/validate_assets.py
npm run check
npm test
```

## 자료·문서 검사

- 복사 목록의 SHA-256을 원본 스냅샷과 대조했다.
- 최상위 README와 새 기획·기술·현황·사례 안내의 내부 링크를 점검했다.
- 발표자료 13개의 PPTX ZIP 무결성을 확인했다. 최신 자료는 36장이다. 기존 발표자료의 레이아웃을 이번에 새로 제작·변경하지는 않았다.
- 인증 파일·원시 대화 로그·모델/의존성 캐시가 수집 대상에 섞이지 않도록 제외 규칙과 Git 적용 목록을 대조했다.
- 일반적인 토큰·비밀키 형식의 문자열 검사를 수행했다. 이 정적 검사는 외부 자산의 재배포 권한 검사와는 다르다.
- 파일 바이트가 클론 후에도 유지되도록 `.gitattributes`에서 줄바꿈 자동 변환을 끄고 전체 파일의 SHA-256 목록을 기록했다.

기존 앱의 변경별 검사 이력은 [원본 QA](../apps/frame/QA.md)에 보존했다. 과거 문서의 테스트 수는 당시 버전의 기록이며 위 최종 검사와 구분한다.

새 사진의 유료 모델 재조사, 외부 검색 서비스의 전면 가용성 검사, 모든 화면의 새 브라우저 시각 검사, 독립 평가셋 정확도 실험, 다중 사용자 운영 시험은 이번 자료 정리 범위에 포함하지 않았다. 기존 화면 캡처와 실제 조사 파일은 해당 작업 당시 산출물이다.
